# Food Plaza 🍔

🚀 Live Demo: https://food-plaza-murex.vercel.app/

## 📌 About Project

Food Plaza is a fully responsive food delivery web application built using React.js. It allows users to browse restaurants, view menus, and manage cart functionality.

## 🛠 Tech Stack

* React.js
* JavaScript
* Tailwind CSS
* Parcel

## ✨ Features

* Restaurant listing
* Menu page
* Search functionality
* Add to cart
* Responsive design
